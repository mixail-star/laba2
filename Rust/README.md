# Задания 1–7 на Rust

Сборка и запуск: `cargo build --release`, затем `target/release/taskN`. Тесты: `cargo test`.

| Задание | Бинарник | Что делает |
|---|---|---|
| 1 | `task1` | Проверка XML-строки стеком, поиск замены одного символа (stdin) |
| 2 | `task2` | Множества в файле: `--file f.txt --query "SETADD имя значение"` (SETADD/SETDEL/SET_AT) |
| 3 | `task3` | Близость геномов по парам символов (stdin: два слова) |
| 4 | `task4` | Проверка ударений: `n`, `n` слов словаря, строка текста (stdin) |
| 5 | `task5` | Вид справа на бинарное дерево поиска |
| 6 | `task6` | Хеш-таблица + фильтр Блума, замер времени |
| 7 | `task7` | LRU-кэш: `cap Q`, затем Q команд `SET x y` / `GET x` (stdin) |

Общие структуры лежат в `src/`: `stack`, `array`, `queue`, `llist`, `hash_table`.
